# ⚙️ GRC Engineering & Compliance Automation

Hands-on cybersecurity engineering portfolio demonstrating how governance, risk, and compliance requirements can be translated into **technical controls, Infrastructure-as-Code, Policy-as-Code, automated compliance testing, and audit evidence collection**.

This portfolio bridges traditional GRC with cloud and security engineering by demonstrating how security requirements can be implemented and validated through automation.

---

## 🧭 GRC Engineering Workflow

**Security Requirements → Infrastructure-as-Code → Policy-as-Code → Automated Validation → Evidence Collection → Continuous Compliance**

The projects in this portfolio demonstrate different components of this workflow across AWS, GCP, Terraform, Open Policy Agent (OPA), Rego, and Conftest.
